# Sources and redistribution

The included simulator/source/tests are selected from the IssueOps project and retain the original MIT license in [LICENSE](../LICENSE). The original copyright notice is preserved. The release adapts `agents/__init__.py` to export only the included deterministic oracles; this adaptation is marked in the source manifest. Scientific reports describe synthetic IssueOps tasks rather than real Jira or customer records. Generic developer identifiers in simulator fixtures are synthetic test data.

M1 uses the SmolLM2-360M Base and Instruct models released by HuggingFaceTB. Model identifiers and pinned source revisions are provided for attribution; no weights, tokenizer files or model-repository materials are redistributed:

- Base revision: `f8027fd0eaeea54caa13c31d31b9fdc459c38b49`.
- Instruct revision: `a10cc1512eabd3dde888204e902eca88bddb4951`.

Earlier feasibility work used WikiText-derived pretraining materials. Those materials, all downloaded third-party datasets, caches, credentials, private repository history, service account identifiers, launch receipts, hardware billing records and manuscript PDFs are excluded.

The public evidence projections preserve scientific fields without private operational metadata. They are new release artifacts; original reports and frozen experiment records remain unchanged in the working archive. The manifest distinguishes copied originals from projections. No claim is made that excluded third-party content is covered by the project license.
